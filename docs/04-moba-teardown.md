# 战斗拆解报告：一款 MOBA 的对抗结构是如何被设计出来的

> 原创作品 ⑤ · 黄渊 · 2027 届雷火「虚拟世界架构师（游戏战斗策划）」投递材料
> 拆解对象：《王者荣耀》公开对局机制（含段位体系、英雄技能、装备系统、经济与节奏结构）
> 立场声明：本人为该作开服玩家，累计时长 10000+ 小时，多个赛季荣耀王者（50 星以上），巅峰赛最高 1900 分。**本文不引用任何内部数值**，全部机制描述基于公开可验证的对局常识；凡涉及具体数字处，均标注为"量级/示意"并给出推导逻辑，不作断言。

## 0. 我为什么要写这份文档

一个玩家玩了 10000 小时，他能得到什么？

大多数人得到的结论是"我知道这个英雄强""这版打野没法玩""这段位队友不配合"。这些话不是错的，但它们**不可执行**。策划拿不到任何可以落地的信息：强多少？为什么强？改哪个旋钮？改完谁会疼？

所以这份文档要回答的不是"王者荣耀好玩在哪"，而是一个更窄、更硬的问题：

> **我把一款玩了 10000 小时的 MOBA，能不能拆成一组可以被讨论、可以被修改、可以被验证的设计部件？**

我的方法来自一个朴素的判断：**战斗策划的核心能力不是"提出创意"，而是"把玩家的模糊感受翻译成可操作的变量"。** 玩家说"手感黏""打不动""这英雄变了"，这些话背后都对应着具体的机制旋钮。翻译是否准确，决定了一个策划能不能在会议上讲出有用的话。

本文的组织方式就是这条翻译链：

```text
玩家语言（体感）
   ↓ 翻译
机制语言（由哪些部件构成）
   ↓ 翻译
变量语言（改什么、改多大、副作用是什么）
   ↓ 翻译
验证语言（改完看什么指标、用什么指标判断成败）
```

全文按这个链条走八章。第八章会把每一章对应到雷火战斗策划的实际工作职责上。

## 1. 拆解方法论：五层时间尺度

### 1.1 为什么必须先分层

新手拆战斗最常见的错误是"一句话论英雄"：把英雄强度当成一个标量，把"这英雄强"当成一个可以讨论的结论。但**强度从来不是一个数，而是一组条件函数**——同一个英雄在不同时间尺度、不同人数规模、不同段位下的强度是不同的，甚至方向相反。

所以我用的第一件工具，是把"一场对局"按时间尺度切成五层。**每一层解决的设计问题完全不同，因此每一层的平衡手段也完全不同。** 这是我认为做战斗设计最该先建立的坐标系。

| 层级 | 时间尺度 | 玩家在想什么 | 策划真正在管什么 | 关键变量举例 |
|---|---|---|---|---|
| **帧层** | 1 帧 ~ 0.5 秒（约 16~500ms） | 无意识，靠肌肉记忆 | 输入的**诚实度**：玩家的意图是否被忠实执行 | 前摇/后摇、取消窗口、判定形状、命中吸附、输入缓冲 |
| **交锋层** | 0.5 ~ 5 秒 | "这波换血我亏不亏？" | 单次交火的**交换比结构** | 技能交换顺序、命中与未命中的收益差、冷却窗口 |
| **对线层** | 5 秒 ~ 数分钟 | "我要不要打、要不要回城？" | 对位的**确定性**与资源的可预期性 | 线权、清线速度、续航、回复成本、召唤师技能冷却 |
| **团战层** | 5 ~ 30 秒 | "我该切谁、该站哪？" | 阵型的**目标优先级**与集火结构 | 阵型距离、开团-接团-收割分工、控制链长度、保护能力 |
| **全局节奏层** | 数分钟 ~ 一整局 | "这局我该怎么赢？" | 优势的**兑现速度**与**可逆性** | 经济曲线、资源置换（线/野/中立资源/塔）、视野、兵线压制 |

**这条坐标系的第一个用处是防止"错层开药方"**：玩家说"这英雄太弱了"，很可能不是数值问题，而是他这一层根本不该承担这个职责——把一个本该在后手位收割的英雄当先手用，任何数值加强都救不了他，只会让他在正确用法下变得更强，从而更难平衡。

### 1.2 每一层的"玩家语言 → 策划语言"翻译

这是本文最核心的一张表。左边是玩家真正说的话，右边是策划该听到的东西。

| 玩家的话 | 所在层 | 策划语言 | 可动的旋钮 |
|---|---|---|---|
| "技能不跟手 / 卡手" | 帧层 | 输入到生效的延迟超过玩家的预期窗口；取消窗口太窄 | 前摇、后退取消、输入缓冲、动画时长 |
| "这技能明明打到了却没中" | 帧层 | **判定与表现不一致**（视觉判定框 < 实际判定框，或相反） | 判定体形状/大小、命中吸附、命中特效同步 |
| "我进去就出不来了" | 交锋层 | 位移进场的**退出成本**高于收益，缺少离场标签 | 位移段数、技能后摇、位移是否可被反手留住 |
| "这波我明明能单杀你却不敢打" | 交锋层 | 交换比的**风险溢价**过高，玩家在做理性避险 | 爆发上限、控制时长、护盾/回复量、召唤师技能 |
| "对线一眼看到结局" | 对线层 | 对位相性**二值化**（0/1），缺少可操作的翻盘窗口 | 续航差异、清线差、射程差、反制标签 |
| "打野一顿抓，我怎么玩" | 对线层+节奏层 | 支援的**影响半径**与时机窗口缺乏反制信息 | 视野成本、支援路径可预测性、塔下保护 |
| "我进去就是送 / 队友永远不上" | 团战层 | 开团收益与开团风险不对等，或阵型信息不可读 | 开团技能的容错、霸体、判定范围、团队增益 |
| "前期打不动后期被翻" | 节奏层 | 英雄的强度-时间曲线与环境曲线不匹配 | 成长系数、装备曲线、中立资源节奏 |
| "这版本某某没法玩了" | 节奏层+环境 | 该英雄的标签组合在当前装备/资源环境中**收益被结构性削弱** | 环境旋钮（装备、资源、召唤师技能）优先于数值 |

**这张表的用法不是背，而是练**：每次听到一句抱怨，先判断它落在哪一层，再判断它是"数值问题"还是"结构问题"。我个人的经验比例是——玩家反馈里真正属于数值问题的不到一半，其余是结构、可读性或环境问题。一个只会调数值的策划，最终会陷入"越调越乱"的循环，因为他在用数值去修补结构。

### 1.3 五层之间的关系：下层决定上层

有一个非对称的规律必须讲清楚：

| 关系 | 结论 | 为什么 |
|---|---|---|
| 帧层 → 交锋层 | 帧层崩则交锋层不可设计 | 判定不可信时，玩家无法形成"该不该打"的判断，博弈退化为赌博 |
| 交锋层 → 对线层 | 交锋层决定对线层的可玩性 | 对线是无数次交锋的累积；单次交锋不成立，对线就只剩补刀 |
| 对线层 → 团战层 | 弱相关 | 对线优势可以换成团战资源，但换不换得成取决于节奏层 |
| 团战层 → 全局节奏层 | 强相关 | 团战是全局节奏的**结算器**：所有前期的积累都在这里兑现 |

**"帧层不可信"是我见过最被低估的设计事故。** 玩家不会说"你的前摇和判定框不一致"，他会说"这英雄很烂"或者"这游戏卡"。他骂的是结果，惩罚的却是整个系统。这决定了我在任何战斗讨论中都会先确认一件事：**我们讨论的是手感问题还是强度问题？** 这两者经常被混为一谈，而它们的解法完全相反——手感问题通常要"减成本"，强度问题通常要"改收益"。

## 2. 英雄身份的解构：能力标签体系

### 2.1 英雄不是"角色"，是标签向量

要给一个英雄做平衡，第一步不是看数值表，而是回答："**这个英雄的能力构成是什么？他占了多少个标签？**"

我用的拆解方式是把所有英雄技能拆成**原子能力标签**，一个英雄 = 一组标签 + 每个标签的权重 + 资源模型 + 操作成本。任何一个英雄都能被写成这样一个向量：

```text
英雄 = {
  标签集合:  [位移(进场), 硬控, 爆发, 清线, 探视野],
  权重向量:  {位移: 中, 硬控: 高, 爆发: 高, 清线: 低, 探视野: 中},
  资源模型:  {消耗类型: 蓝/能量/无, 冷却量级: 短/中/长, 回复来源: 无},
  成本模型:  {操作复杂度: 高, 学习成本: 中, 容错率: 低},
  时间曲线:  {前期: 强, 中期: 强, 后期: 弱},
  尺度曲线:  {1v1: 强, 5v5: 中, 侧翼: 强}
}
```

这个写法的价值在于：**它让"加强这个英雄"这句话变得可以反驳。** 当有人提议"给他加个位移"时，我可以立刻问：他的标签数是不是已经超了？他缺的到底是标签，还是数值权重？他的时间曲线是不是本来就该接受妥协？

### 2.2 能力标签库

下面是我归纳的标签库。分成四类：**移动、控制、输出、支持**。这张表本身不长，但它是后面所有分析的地基。

| 类别 | 标签 | 机制含义 | 设计上的代价（为什么不能白给） |
|---|---|---|---|
| **移动** | 突进位移 | 主动向目标/方向移动 | 会带来强开团与逃生双重收益，必须用冷却或后摇收费 |
| | 瞬移位移 | 无路径、可穿墙 | 反制难度高（不可被路径拦截），通常配长冷却 |
| | 位移克制 | 对抗位移的手段（拦截、减速、地形、控制） | 若普及，会让位移类英雄整体贬值 |
| **控制** | 硬控 | 眩晕/击飞/击退等使目标无法行动 | 命中即产生**不可反抗的时间**，是最贵的标签 |
| | 压制级控制 | 无法被常规解控手段解除的最高优先级控制 | 反制手段近乎为零，因此必须捆绑施法者的高成本（如自身也受限制） |
| | 软控 | 减速、减攻速、降低输出效率 | 反制成本低，属于节奏工具 |
| | 霸体/免控 | 施法期间不受控制 | 等价于"把对手的控制标签作废"，强度极高 |
| **输出** | 爆发 | 短时间内的伤害集中 | 需要前置条件（位移进场、控制命中）来平衡 |
| | 持续输出 | 单位时间内稳定的伤害流 | 需要时间兑现，因此依赖容错与保护 |
| | 真实伤害/穿透 | 绕开防御属性的伤害通道 | 会让"堆防御"这条成长线贬值，必须稀缺 |
| | 斩杀型收益 | 对低血量目标的额外收益 | 强化滚雪球，需谨慎配给 |
| **支持** | 护盾/减伤 | 提供临时有效生命 | 与治疗不同，是**预防型**资源，更可预期 |
| | 回复/续航 | 提供持续有效生命 | 直接决定对线层的确定性，是"一眼看到结局"的主因之一 |
| | 视野/探测 | 提供信息 | 信息即优势，且不可被数值抵消 |
| | 清线/清野 | 快速处理兵线与野区 | 决定影响半径——这是"节奏权"的物质基础 |
| | 团队增益 | 为队友提供属性/状态 | 个体强度低、团队价值高，是"个体 vs 团队"矛盾的物质载体 |
| | 重伤/破甲等减益 | 削弱对手的防御或回复通道 | 是环境级的反制工具，会影响整个英雄类别 |

### 2.3 英雄身份 = 标签组合 + 数值权重 + 时间曲线

我把玩家最熟悉的分路/职业，翻译成标签组合来看。这是一张我在分析任何英雄时都会在脑子里过一遍的表：

| 英雄类型 | 典型标签组合 | 缺什么 | 强度曲线 | 平衡难点 |
|---|---|---|---|---|
| **开团坦克** | 硬控 + 进场位移 + 坦度 + 探视野 | 爆发、清线、独立作战 | 中期最强，后期坦度相对贬值 | 硬控命中率决定其"强度感"，容错一旦过高就无解 |
| **收割刺客** | 爆发 + 进场位移 + 离场手段 | 坦度、清线、正面作战 | 中后期（依赖装备成型） | 进场成本与退出成本只要一项过低，就会压死后排 |
| **持续射手** | 持续输出 + 射程 | 位移、坦度、先手 | 后期（随时间与装备放大） | 无位移是它的代价，一旦环境不缺保护，它就是最强 |
| **控场法师** | 硬控/软控 + 爆发或消耗射程 + 清线 | 坦度、续航 | 中期（清线与支援） | 控制与清线同时拉满时会变成"无脑强" |
| **续航战士** | 回复/续航 + 坦度 + 位移 | 纯爆发、远程手段 | 全期平滑（曲线最稳） | 曲线太平滑 → 缺少被针对的窗口 → 成为"版本答案" |
| **游走辅助** | 视野 + 团队增益 + 软控 | 个体强度 | 全期（靠增益放大队友） | 个体强度低是设计代价，一旦给足强度就变成"兼职输出" |

表里每一行都在回答同一个问题：**这个英雄的"缺什么"才是他的身份本身。** 一个没有任何缺点的英雄，不是最强的英雄，是**没有身份的**英雄——他不会有对位相性，不会有克制关系，也不会有玩家愿意专精的理由。这引出下一节最重要的一个诊断工具。

### 2.4 诊断工具：标签溢出与标签空缺

我把两个最常用的诊断写成一句话：

> **英雄强度溢出，绝大多数时候不是因为数值太高，而是因为标签数量超出了他的设计定位。**

具体来说有两种病：

| 病症 | 定义 | 玩家体感 | 策划语言 | 修法优先级 |
|---|---|---|---|---|
| **标签溢出** | 一个定位为 X 的英雄，同时拥有不属于 X 的关键标签（例如坦度 + 硬控 + 位移 + 回复四项齐全） | "这英雄没有弱点""打不死还留不住" | 该英雄的克制关系被自己的标签冗余堵死了 | 先删/弱化"越位标签"，再谈数值 |
| **标签空缺** | 一个定位为 X 的英雄，缺少完成 X 职责的最低标签（例如一个开团位没有稳定硬控） | "这英雄就是个工具人""选他干嘛" | 他的职责无法被兑现，数值加强也只是让他变成数值怪 | 先补职责标签，再调权重 |

**这两个诊断的顺序不能颠倒。** 很多平衡事故的源头是：策划先调数值，发现怎么调都不对，最后才发现是标签结构问题——而这时玩家的认知已经被几轮数值改动污染了。

### 2.5 一个例子：为什么"有位移"和"能留人"必须分开定价

用公开机制常识举一个我认为最干净的对照：**有位移的英雄**与**能阻止位移的英雄**，在玩家口中的评价经常是"强"与"没用"，但它们在设计上的定价逻辑完全不同。

| 能力 | 玩家的收益感知 | 反制方的可操作性 | 定价逻辑 |
|---|---|---|---|
| 位移（进场） | 极高（"我能决定什么时候打"） | 低（位移不可被路径拦截） | 必须用**冷却/后摇/资源成本**来收费 |
| 位移（离场） | 极高（"我打得过就打，打不过就跑"） | 极低 | 必须用**次要功能缺失**来收费（例如离场手段=输出手段，用一次就没了） |
| 留人（软控/硬控） | 高（"我先手就是优势"） | 中（可被解控/净化/站位规避） | 用**命中难度**来收费 |

**这张表说明一件事：同一个"位移"标签，进场和离场的定价完全不同。** 进场位移的代价是"进入对手的攻击范围"，这是天然的成本；离场位移没有天然成本，必须人为加成本。很多关于"某英雄溜得快、抓不死"的争议，本质不是数值问题，而是**离场位移没有被充分收费**。

用户提供的框架要求我用公认的英雄类别来举例，我选择用标签结构去指代类别（如"拥有进场位移 + 硬控的开团型英雄"）而不逐一点名比较具体强弱，原因很实际：**一份作品集里对具体英雄做强度断言，无法被验证，也无法被复用；而标签结构的分析可以被任何版本复用。** 这不是回避，是设计沟通中应当保持的严谨性——只有官方数据能承担对具体英雄做强度断言的举证责任。

## 3. 对抗结构的三个核心矛盾

所有 MOBA 的对抗结构，说到底由三组矛盾撑起来。**这三组矛盾不是"问题"，而是"张力"**——它们是体验的来源，策划要做的是让张力保持在不崩的区间内，而不是消灭它。

### 3.1 矛盾一：先手权 vs 后手权

**先手权**指"我有能力决定这场交锋什么时候开始"；**后手权**指"我能决定这场交锋什么时候结束"。

这两者是根本对立的：先手方把对手拉进自己的节奏，后手方则需要先手方"交底牌"。一个健康的对抗结构，必须让**先手是有风险的**。

| 维度 | 先手方的收益 | 先手方的成本 | 后手方的收益 | 后手方的成本 |
|---|---|---|---|---|
| 交锋层 | 决定交战时机与位置 | 交出关键技能，进入对手射程 | 反手控制可打断对方节奏 | 需承受第一波爆发的容错 |
| 团战层 | 可集火指定目标 | 阵型前压、与队友脱节 | 站位更整、可等对手脱节 | 被动接团、失去选择权 |
| 节奏层 | 用人头换资源窗口 | 若开团失败，全队空窗 | 可拖延换时间 | 时间站在对手一边 |

**关键设计命题：先手的收益必须与"开团技能命中率"强绑定。** 一旦开团技能要么必中、要么在施法期间不可被打断（霸体）且命中判定宽容，先手就变成了"免费优势"——玩家会得到一种非常具体的负面情绪："**他随便动了一下，我们就输了。**"这句话翻译成策划语言就是：**先手权没有被充分收费。**

反过来，如果先手成本过高（开团必被反杀），会出现另一种病：双方都不先手，对局被拖入无交火状态。这就是"僵持病"。**先手与后手的平衡点，本质是在"敢于出击"和"不能免费出击"之间找一条线。**

### 3.2 矛盾二：爆发 vs 持续

这是**时间维度上的矛盾**。爆发是"把伤害压缩到极短窗口内兑现"，持续是"把伤害摊平到长时间里兑现"。

| 对比项 | 爆发型 | 持续型 |
|---|---|---|
| 兑现条件 | 前置命中（控制/近身/预判） | 存活时间 + 输出位置 |
| 容错方向 | 技能空 = 强度归零 | 站位差 = 被秒 |
| 强的时间段 | 前中期（装备门槛低即可杀人） | 中后期（装备与时间的乘算） |
| 需要的队友 | 先手/控制/视野 | 保护/治疗/开团牵制 |
| 玩家体感 | "我能一波带走" | "我站得住就赢了" |
| 设计上的天然代价 | 后期相对贬值 | 前期几乎没有威胁 |

**这里有一个不能破的边界：如果爆发型英雄在后期仍能稳定秒杀持续输出核心，那么持续输出这个设计类别就失去了存在意义。** 因为持续型的全部价值来自"时间"，一旦它拿不到时间，它带来的就只有负体验——玩家会得出"要什么射手，大家一起冲"的结论，然后整个游戏的战术结构会退化为"五个爆发型英雄互秒"。

这条边界怎么守住？公开的机制常识给出了很清晰的答案模式：

- **用成长曲线做时间折扣**：爆发型英雄的伤害成长相对前置，持续型的输出随装备与时间放大；
- **用有效生命做对抗**：持续输出位在装备成型后可获得的"抗秒杀"手段，是它兑现时间的前提；
- **用装备作为环境旋钮**：当"抗秒杀"类装备被削弱时，被压缩的不是射手这一个位置，而是**整个"时间型输出"的生态位**。

### 3.3 矛盾三：个体强度 vs 团队价值

1v1 强不强，和 5v5 有没有用，**是两个不同的指标，而且经常反向**。

| 类型 | 1v1 强度 | 5v5 价值 | 价值来源 | 玩家的典型评价 |
|---|---|---|---|---|
| 单挑/边路型 | 高 | 中 | 独立兑现，牵制兵线 | "我能单带，但团战没用" |
| 团队增益型 | 低 | 高 | 放大队友的输出/生存 | "我自己打不过，但我能让你们赢" |
| 开团型 | 中 | 高 | 提供唯一稀缺资源：**先手权** | "打得好的开团是全场最有价值的一手" |
| 收割型 | 高 | 高（但依赖他人） | 兑现队友创造的残局 | "队友开了我才强" |

**"个体强度 vs 团队价值"决定了 BP（选人）阶段的全部逻辑。** 因为玩家永远可以选出五个单体最强的英雄，但只要这一组阵容存在**标签空缺**（没有先手、没有清线、没有视野、没有持续输出），它在团战层的价值就会低于一组单体偏弱但互补的阵容。

这就构成了整个对抗结构的收口：**单体的强弱是可比较的，组合的价值是不可直接比较的。** 这个不对称，正是"选人阶段"能成为独立博弈层的原因。

### 3.4 三组矛盾如何构成 BP 博弈

BP（Ban/Pick，禁用与选用）阶段在高端局与巅峰赛都是独立胜负手。把它翻译成设计语言，它是这样一个问题：

> **在信息不完全、且对手能对你的选择做出回应的情况下，双方如何在"标签资源池"里争夺组合最优解。**

| BP 环节 | 玩家在做什么 | 策划语言 | 决定因素 |
|---|---|---|---|
| 禁用 | "把那个我处理不了的按掉" | 封锁**不可反制的标签组合** | 反制成本 > 收益的组合，会被系统性禁用 |
| 一抢 | "先把版本最强的招牌抢过来" | 争夺**高权重标签的可替代性**（独一份的越稀缺越贵） | 该标签是否具有唯一提供者 |
| 后手针对 | "他有位移，我拿一个能留人的" | 在**反制矩阵**上做覆盖 | 反制关系是否被玩家感知到 |
| 补位 | "我们缺一个清线的" | 修补**阵容标签空缺** | 空缺是否可被外援手段（装备/召唤师技能）弥补 |
| 全局收敛 | "这局我们就打前期" | 选择**兑现节奏的窗口** | 阵容的时间曲线是否一致 |

**BP 的本质不是"选强的"，而是"选一致的"。** 一组五个人各自选自己最强的英雄，往往在时间曲线上是分裂的——前期英雄等不到后期，后期英雄扛不住前期。所以 BP 的真正胜负手是：**双方谁能在自己的阵容里建立起"一致的兑现节奏"，同时破坏对手的节奏一致性。**

这也解释了为什么禁用阶段最有价值的往往不是"最强的英雄"，而是"最能破坏我方节奏一致的英雄"——即**反制位**。

| 阵容自查项 | 缺失时的后果 | 玩家语言 |
|---|---|---|
| 是否有先手手段 | 团战只能被动接团 | "没人开团" |
| 是否有持续输出 | 打不动坦度高的阵容 | "打不死人" |
| 是否有清线能力 | 兵线压力锁死，资源无法置换 | "线推不出去" |
| 是否有反制位移手段 | 对手能够自由进出战场 | "留不住人" |
| 是否有视野/探测 | 被逐个击破，信息劣势 | "全程被绕后" |

**这张表是我判断一局阵容是否健康的最快工具**，也是我把"玩家经验"升级成"可复用工具"的证明：一个玩家说"这阵容没法打"，我可以说清楚他感受到的到底是哪一项空缺。

## 4. 平衡的调控旋钮

一个英雄过强，策划手上到底有哪些"可拧的旋钮"？这一章我把它整理成一份**操作手册**，并给出优先级与副作用评估——因为改动的真正难点从来不是"能不能改"，而是"**改完玩家会怎么理解这次改动**"。

### 4.1 旋钮全景

| 旋钮类别 | 具体手段 | 见效速度 | 对玩家感知的影响 | 副作用风险 |
|---|---|---|---|---|
| **数值旋钮** | 基础伤害、成长系数、冷却、消耗资源、射程、移速 | 快（一个版本内可感知） | 强（"打不死/打不动"） | 反复数值摆动会让玩家失去对英雄的手感记忆 |
| **机制旋钮** | 增删标签（位移/霸体/控制类型）、技能段数结构、判定逻辑 | 中（依赖玩家重新学习） | 极强（直接改变英雄身份认同） | 可能造成"英雄不是我的英雄了" |
| **手感旋钮** | 前摇/后摇、取消窗口、命中吸附、动画与判定对齐 | 中（需实测） | 极强（"跟不跟手"） | 影响所有玩家，且极难用文字说明 |
| **成本旋钮** | 学习成本、操作复杂度、资源成本（能量/蓝耗） | 慢 | 中（会重新划分熟练玩家与新手） | 抬高门槛会缩小该英雄的玩家基数 |
| **环境旋钮** | 装备、召唤师技能、中立资源节奏、野区结构 | 慢（间接） | 分散（玩家很难归因到环境） | **最难预测**：会连带影响未被点名的一整类英雄 |

### 4.2 调整的优先级：先动"便宜的"，再动"贵的"

我给自己定的决策顺序是这样的。这个顺序不是官方流程，而是我在长期观察版本迭代后总结的**风险控制顺序**：

```text
第 1 步：先问这是"数值问题"还是"结构问题"
        → 若该英雄的优势来自对手没有选择（标签空缺被封死），先动结构

第 2 步：优先动"可被玩家读取、且不改变核心标签"的量
        → 成长系数、冷却量级、消耗成本：影响大、解释成本低

第 3 步：其次动"手感与容错"
        → 前摇、判定范围、吸附：感知极强，但会让老玩家手感记忆作废，必须慎重

第 4 步：其次动"成本与门槛"
        → 抬高操作/资源成本：把强度重新分配给熟练玩家，而非直接砍掉

第 5 步：最后才动"标签本身"
        → 增删能力标签：改动最小但代价最大，等于重写英雄身份
```

**为什么顺序是这个？** 因为越靠下的旋钮越接近"玩家投入的不可转移资产"。一个玩家在某个英雄身上投入的时间，构建的是**肌肉记忆与战术直觉**，这部分资产对数值改动有容忍度，对机制改动几乎没有容忍度。一个降低数值的英雄还是同一套连招，一个改掉核心位移的英雄等于换了一个新英雄——但玩家的皮肤、熟练度、情感寄托还在原位。

### 4.3 副作用清单：每一刀砍在哪里，玩家疼在哪里

这张表是我认为"平衡调整中最重要的沟通材料"。策划容易只算伤害，不算情绪。

| 改动 | 直接效果 | 玩家第一感受 | 二次反应（几周后） |
|---|---|---|---|
| 降基础伤害 | 爆发降低 | "打不动了" | 重新配装，可能发现新打法（若幅度克制） |
| 降成长系数 | 后期上限降低 | 前期几乎无感 | 后期体验崩坏，玩家开始"抢时间"，加速雪球 |
| 加冷却 | 输出频率降低 | "卡手、节奏断" | 若超出容错阈值，会放弃该英雄 |
| 降射程 | 安全距离缩短 | 极强（"手感完全变了"） | 定位漂移（该英雄被迫靠近战逻辑玩） |
| 加前摇 | 反应窗口变大 | "操作不跟手、判定不可信" | 归因为"这游戏卡"，而不是"英雄被削" |
| 删核心标签 | 克制关系变化 | "这不是我玩的那个英雄" | 老玩家流失，新的强度感知需要一整季重建 |
| 加前置条件 | 强度须先满足条件 | 前排玩家理解，后排玩家"怎么不生效" | 该英雄的胜率方差变大（强者更强，弱者更弱） |
| **加强弱势英雄** | 强度上升 | 正面情绪，"终于被看见了" | 若加强错位，会造成"影子超标"（对手受害） |

**这里有一条我认为最重要的感知规律：玩家对"被拿走的东西"的记忆强度，远高于对"被给予的东西"。** 这解释了为什么削弱比加强更容易引发情绪反应，也解释了一个版本里"削 A 加 B"和"只削 A"在数据上可能等价、在舆论上却完全不等价。

因此一个成熟的平衡沟通，至少要做到两件事：

1. **成对改动**：如果必须削弱某英雄的核心体验，就同时在他的次要维度或环境上给出补偿，让玩家看到"这次调整不是针对我"；
2. **可读的改动说明**：机制改动必须让玩家能从游戏内表现理解原因（视觉/音效/文本提示变化），否则玩家会把改动读成 bug——**被当成 bug 的改动，等于既损伤了体验又没有换来平衡收益。**

## 5. 平衡的两种哲学：削弱强势 vs 加强弱势

### 5.1 各自的适用场景

| 维度 | 削弱强势（Nerf） | 加强弱势（Buff） |
|---|---|---|
| 适用条件 | 强度来自**标签溢出**或**先手/反制的不可解** | 强度不足来自**环境变化**（装备、资源节奏、对位生态） |
| 判断依据 | 对手"没有选择"，即使打得好也处理不了 | 该英雄的定位职责无法被兑现，而不是数值偏低 |
| 优点 | 见效快，直接压缩上限，能立刻恢复可玩性 | 提升阵容多样性，保护玩家已投入的操作资产 |
| 缺点 | 连带伤及熟练玩家、"技能折旧"、可能杀死一个玩法角色 | 易引发数值膨胀、并强化该英雄的克制对象（错配） |
| 对玩家情绪 | 负向（损失厌恶被激活） | 正向（"被重视"） |
| 长期风险 | 反复削弱会让该类英雄的操作上限被整体压低，玩法收敛 | 加法累积会造成"强度通胀"，对局节奏被动加速 |

### 5.2 为什么"只做加法"不可行

这是一个可以严格推演的结论，不是立场问题。

**强度是相对的。** 假设所有英雄的输出能力都上调一档，那么相对强弱格局完全没有变化——但下面这些量变一定会发生：

| 被改变的量 | 变化方向 | 连锁后果 |
|---|---|---|
| 团战时长 | 缩短 | 容错窗口变小 → 先手方优势被放大 → 主动性英雄的价值提升 |
| 有效反应时间 | 缩短 | 操作精度的价值下降 → 手感与预判类英雄贬值 |
| 防御/生存类标签的价值 | 相对贬值 | 坦克与保护型辅助的生态位被挤压 → 阵容趋同 |
| 血压曲线 | 整体抬升 | 体验从"博弈"偏向"互秒"，负面情绪上升 |
| 平衡难度 | 上升 | 每次调整的绝对影响被放大，误差容忍度下降 |

也就是说：**"全员加强"不是平衡，而是把整局游戏的节奏向"更快、更凶、容错更低"的方向整体平移了一次。** 玩家的感知会非常直接——"现在一波没打死人就输了"。

所以正确的做法不是"加"或"减"，而是**结构性再分配**：

> **给一个标签，就要收回另一个标签；提高一个维度的收益，就要抬高它的兑现成本。**

这也是我在分析版本改动时最看重的一条判据：**一次健康的调整，应当在"强度总和"上接近零和，而在"强度分布"上有所移动。**

### 5.3 一个三角约束：可读性、强度、学习成本

任何新英雄或机制改动，都同时受三个约束拉扯。这三个角**不可能同时拉满**：

| 想要 | 代价 | 现实后果 |
|---|---|---|
| 强度高 | 必须加可读性（让对手有反应窗口）或加学习成本 | 否则出现"无解机制" |
| 可读性高（对手容易理解与应对） | 必须降强度或降惊喜度 | 否则玩家感受不到"秀操作"的空间 |
| 学习成本低（新手友好） | 必须降强度上限 | 否则成为"无脑强"，引发老玩家不满 |
| 三者都想高 | —— | 结果通常是"上线即超标，随后被砍到另一个极端" |

**"上线即超标→被削到冷门"是行业里最典型的失败循环**，而它的根因往往不是数值预估失误，而是**设计时在三者之间做了不可能的承诺**：既要强、又要好懂、又要好上手。

### 5.4 我的平衡决策流程图

把上面几节压缩成一棵可以实际使用的决策树：

```text
某英雄强度超预期
  │
  ├─ 是"标签溢出"吗？（拥有不属于其定位的关键标签）
  │     └─ 是 → 先弱化越位标签，再评估数值是否需要动（结构优先）
  │
  ├─ 是对手"没有选择"吗？（反制成本 > 反制收益）
  │     └─ 是 → 给对手一个反制旋钮（反制标签/装备/召唤师技能）
  │          而不是只砍伤害 —— 砍伤害只降低他"赢"的概率，不改变他"无法被处理"的性质
  │
  ├─ 是环境变化导致的相对过强吗？（装备/资源/节奏利于他的标签组合）
  │     └─ 是 → 优先动环境旋钮（影响范围大，但避免玩家被"点名"的情绪代价）
  │
  ├─ 是"强度来自数值权重"吗？（标签结构无问题，仅兑现效率过高）
  │     └─ 是 → 动数值旋钮，并同步检查其时间曲线是否被破坏
  │
  └─ 以上都不是，纯粹是"玩家不会用"导致的胜率偏低
        └─ 什么都不改，改教学/提示/引导 —— 这属于体验问题，不属于平衡问题
```

**最后一条我要特别强调。** 用平衡改动去修"玩家不会用"，是平衡工作里最常见的无效消耗：它既没有提高该英雄的强度上限，又污染了数据，让后续判断失去基线。**先分清"变弱"还是"没被用明白"，是平衡工作的第一道分诊。**

## 6. 从玩家视角观察到的问题

这一章是本文档最关键的部分，也是最容易被写成"吐槽"的部分。我刻意做了三件事来避免它退化成抱怨：

1. **只写有具体触发场景的体验**（能复述出"什么情况下会发生"），不写模糊的不爽；
2. **每个观察都给出策划语言的对应描述**，证明它指向一个可修改的设计缺陷；
3. **不点具体英雄做强度断言**，只描述机制结构——因为强度断言需要官方数据支撑，而结构描述可以被复用。

### 问题一：对位结局的"前置可预测性"——一眼看到结局

**体验描述。** 有些对位从选人结束、甚至从一级上线的那一刻起就已经注定。玩家会在开局一分钟内得出一句非常具体的判断："这把我只要不送就不会输"或"这把我打不出任何东西"。之后的对线期不再是博弈，而是**走流程**：补刀、等队友、等时间。

**策划语言。** 对位的相性关系出现了**二值化**——本该是一条连续的优势曲线（六四开、七三开），实际表现接近 0/1。当一方缺乏任何可操作的反制窗口时，对线层就不再承载"决定"，只承载"等待"。

**根因拆解。** 相性二值化通常由三种标签不对称造成：

| 不对称类型 | 具体表现 | 为什么无法被操作弥补 |
|---|---|---|
| **续航不对称** | 一方能持续回复，另一方不能 | 每次换血都是净亏损，打得越久差距越大，玩家只能放弃交战 |
| **射程/清线不对称** | 一方可安全处理兵线，另一方必须靠近 | 线权与安全距离被同时拿走，对手连"用操作换资源"的机会都没有 |
| **反制手段不对称** | 一方有位移/霸体，另一方没有任何抗拒手段 | 对抗变成单向操作，被针对方唯一的策略是"不打" |

**指向的设计缺陷。** 对位设计缺少**"代价化"处理**：优势方获得优势时没有承担足够的成本（比如用续航换清线、用位移换坦度）。当优势是免费的，"一眼看到结局"就是必然结果。

**为什么这个问题值得策划重视：** 对线层承担的是**体验中的"过程感"**。玩家最难忘的对局，往往不是碾压局，而是"我先被压，后来靠一次判断翻回来"的局。相性二值化会系统性地删掉这类记忆点。

### 问题二：无法被反制的机制——"我什么都做不了"

**体验描述。** 有一类死亡让玩家不觉得"我犯了错"，而觉得"我没有被允许参与"。典型场景是：从被控住的第一帧到死亡结算，玩家的输入可以按、但没有任何效果；或者他明明看见了对方要做什么，也知道该躲，但躲不了。

**策划语言。** 这属于**反制成本 > 反制收益**的机制设计：对手应对该机制的代价（需要提前几秒预判、需要特定的英雄或装备、需要队友在场）远大于他能得到的收益（活下来）。当反制成本超过门槛，玩家在理性上就会放弃反制——他会记住的不是"我该怎么做"，而是"这游戏不让我玩"。

| 机制类型 | 反制窗口 | 反制手段 | 玩家体验 |
|---|---|---|---|
| 有前摇可躲的控制 | 明确 | 站位、位移、解控 | "我该躲，我下次会躲"——**这是健康的设计** |
| 无提示/极短前摇的强控 | 近乎无 | 几乎无 | "我什么都做不了" |
| 不可被常规解控手段解除的高优先级控制 | 无 | 需队友介入 | "只能等死" |
| 施法期间免疫控制（霸体）的进场 | 无（针对击飞/眩晕类反手） | 只能拉开距离 | "留不住他" |
| 长时间无法被选中的状态 | 由对方决定 | 只能等 | "他在秀，我在看电影" |

**根因拆解。** 这类机制的共同点是**把"博弈"替换成了"执行"**：只要条件满足，结果就锁定。它短期带来的爽感非常强（"我这波操作帅"），但它在整个对抗结构上是净负的，因为它删掉的是对手的**参与权**——而参与权是竞技游戏里最不能删的东西。

**这里有一个我必须写清楚的辩证：不能把所有强控都视为设计缺陷。** 强控本身是必要的：它是"先手权"这种稀缺资源的载体，也是惩罚站位错误的唯一手段。问题不在"有强控"，而在**强控缺少"宣告"与"可打断性"这两件事**：

```text
健康的强控 = 高收益
             + 清晰的宣告（玩家能读出"要来了"）
             + 明确的可打断/可规避路径
             + 施法者的真实成本（位置暴露/自身受限/长冷却）

有问题的强控 = 高收益
             + 无宣告 或 无规避路径
             + 施法者几乎不承担风险
```

**这条等式是我判断"某个控制算不算无解"的唯一标准**，它不依赖任何内部数值。

### 问题三：英雄身份漂移——"这不是我玩的那个英雄"

**体验描述。** 经历过几个版本的玩家通常会有一次非常具体的失落：某个英雄被改动之后，他的胜率可能没有变化，甚至更高了，但玩起来**不是同一个人了**。玩家会说"他现在变成了另一个英雄"，或者干脆换人。

**策划语言。** 这是**标签锚点被替换**导致的身份认同断裂。英雄的身份由"核心标签 + 它的兑现方式"共同定义，而不是由"强度"定义。当一个英雄的强度被以"删掉核心标签、补上数值"的方式处理时：

| 变化 | 强度数据 | 玩家认知 | 结果 |
|---|---|---|---|
| 核心标签保留，数值下调 | 下降 | "还是他，只是没那么强了" | 玩家接受度较高，愿意继续专精 |
| 核心标签删除，数值补足 | 基本不变 | "完全不是他了" | 熟练资产作废，专精玩家流失 |
| 核心标签的兑现方式改变（条件变多） | 不变 | "要按的顺序不一样了" | 需要一整个赛季重新学习，阵痛明显 |

**根因拆解。** 这类问题的根源往往是**用数值手段去解决结构问题**：策划发现该英雄"强度不好调"，于是替换掉难以量化的标签（例如把"进场开团"改成"远程消耗"），使强度落进一个更容易控制的区间。这在数据上通常是成功的，但在体验上是失败的——因为**英雄的标签组合本身就是玩家的情感资产**。

**我认为可以提炼成一条设计纪律：**

> **强度可以下调，但定位标签不应被替换；如果必须替换，就必须同步替换叙事、视觉表现与教学引导，并且明确告知玩家"这是一次重做，不是一次削弱"。**

### 问题四：强度与"可见性"不匹配——"他怎么还有大招"

**体验描述。** 高端对局里，玩家会默数对手的关键技能冷却，这是一种真实的、可积累的技术资产。但在中低对局中，玩家经常在"以为对手交完技能了"的前提下进场，然后被反杀——而他之所以判断错误，不是因为他数错了，而是因为**整个游戏没有给他可读的依据**。

**策划语言。** 这是**信息可见性（Readability）与深度（Depth）之间的取舍失衡**：关键状态的呈现不足，导致同一套机制呈现两种极端体验——中等玩家体验随机（"猜的"），高端玩家体验可控（"我数过了"）。

| 信息类型 | 当前可见性 | 中等玩家的体验 | 高端玩家的体验 |
|---|---|---|---|
| 对手血量/蓝量 | 高（有明确 UI） | 能判断 | 能判断 |
| 对手关键技能是否就绪 | 低（依赖记忆） | 随机 | 转化为技术优势 |
| 对手召唤师技能是否就绪 | 极低 | 完全靠猜 | 技术优势更大 |
| 自身施法条件是否满足 | 高 | — | — |

**这个问题的价值在于它揭示了一个常被忽略的真相：信息不足不等于深度。** 深度来自"有依据的判断"，随机来自"无依据的猜测"。把关键状态做成完全不可读，看起来是把"技术上限"抬高了，实际上是把"大多数玩家的体验下限"降到了随机水平——而大多数玩家才是留存的主体。

**但我也必须承认反面：过度可视化会削减高端玩家的技术资产。** 一个把所有冷却都做成进度条的游戏，会让"记 CD"这项技术失去价值，从而削弱一部分核心玩家的成就感。所以这不是"该不该做"的问题，而是"**做成什么精度**"的问题。

### 问题五：装备与英雄的乘法耦合——"到底谁超标了"

**体验描述。** 很多版本答案的出现路径是这样的：某件装备被加强 → 某个原本中规中矩的英雄突然变成非禁即选 → 舆论认为"这个英雄太强了" → 英雄被砍 → 装备又被削 → 这个英雄变成永远翻不了身的冷门。

**策划语言。** 这是**环境旋钮的连带效应**：装备的属性不是加到英雄身上，而是与英雄的标签与成长曲线**相乘**的。同一个装备改动，对不同英雄的增益幅度可以相差数倍，而策划在改动时的评估对象通常是"平均收益"而不是"分布收益"。

| 耦合形式 | 说明 | 后果 |
|---|---|---|
| 标签放大 | 装备效果与某英雄已有的标签同向叠加（如减伤类装备 × 已有坦度标签） | 该英雄受益远超平均 |
| 曲线耦合 | 装备填平了某英雄的成长曲线谷底 | 该英雄失去时间代价，变成全期曲线 |
| 反制链断链 | 某种反制装备被削弱 | 反制链上游的英雄集体失去活路 |

**这条观察直接对应一个我认为非常重要的数据阅读纪律：**

> **聚合胜率不能跨段位、跨对位、跨阵容直接平均。** 同一个英雄在顶峰段的胜率与在中段位的胜率常常表达完全不同的东西——前者可能体现"上限被过度兑现"，后者可能体现"下限太低导致队友体验差"。如果一个调整只针对总平均值，就必然同时得罪两端。

**这也是我认为"策划必须亲自玩游戏"的真正理由**：数据能告诉你发生了什么，但只有亲身体验能告诉你**玩家在什么时候、因为什么原因决定了放弃**。数据里没有"我这一整局都在等"这句话。

## 7. 我的设计改进设想

上一章提出的问题里，我选择三个**可以落地、且风险可控**的方向给出具体方案。每个方案都按"机制怎么改 → 预期效果 → 风险与配套措施"来写，并明确标注哪些是示意性的设计参数（非官方数值，仅为说明量级）。

### 方案 A：把"不可解控制"改造成"可宣告、可打断、有成本"

**要解决的问题：** 问题二（无法被反制的机制）。

**机制怎么改（三件事同时做）：**

1. **强制宣告期**：所有高优先级（不可被常规解控手段解除的那一类）控制技能，在生效前必须存在一个**视觉上明确、时间上可被反应**的宣告段（量级参考：足够让对手做出一次有意义的操作决定，具体帧数需在原型中实测标定）。宣告不等于提示，它必须是**能改变对手行为的信号**。
2. **施法者绑定**：控制的持续时间与施法者的状态绑定——施法者被打断/位移/脱离指定关系，控制随即终止。这条的价值在于把"控制"从一次性的命中判定，变成一段**持续的博弈过程**：控制方必须承担维持成本，被控方的队友有了明确的救援目标（打施法者）。
3. **成本显性化**：施法者在使用该技能后必须进入一个真实可感的脆弱窗口（自控身、位置暴露、长时间冷却三者的组合），让"成功强控"与"施法者承担风险"成为同一件事。

| 项目 | 内容 |
|---|---|
| **预期效果** | 强控从"免费优势"变成"有风险的赌博"；团战出现"救援"这一新的博弈环节；被控方及其队友获得明确的应对目标，负面情绪从"我什么都做不了"转为"我没救到" |
| **配套措施** | 强控成功后给施法者团队提供一次**明确的团队收益**（否则会削弱开团位的价值感）；同步检查装备与召唤师技能中的解控手段是否被过度依赖 |
| **风险** | ① 开团型英雄整体变弱，阵容主动性下降，对局趋于保守——需要用"成功开团的团队收益"补偿；② 宣告期过长会让强控变成"永远不会命中"，需要按技能定位分别标定；③ 复杂化带来学习成本，需要一次性教学与视觉语言设计 |

### 方案 B：用"反制标签对"把对位从二值化拉回连续优势

**要解决的问题：** 问题一（对位一眼看到结局）与问题五（反制链断链）。

**机制怎么改：**

1. **建立"标签—反制标签"配对表**，并把它作为**设计约束而非事后补丁**：每一类强势标签都必须有至少一个可被普遍获取的反制通道。示意性配对：

| 强势标签 | 反制标签（须可由多个英雄/装备/召唤师技能提供） | 反制成本目标 |
|---|---|---|
| 进场位移 | 留人（软控/硬控）、地形限制、反位移 | 低于"被进场带走"的损失 |
| 离场位移 | 持续减速/标记、视野锁定 | 中（需提前布控） |
| 爆发 | 抗秒杀（护盾/减伤/无敌窗口） | 中（需装备或技能位） |
| 持续回复 | 重伤类减益 | 低（可通过装备获取） |
| 高射程消耗 | 视野/绕后/位移进场 | 中高 |
| 霸体免控 | 非控制类惩罚（伤害反馈、资源消耗） | 中 |

2. **给"没有位移"的英雄一个可操作的防御手段**，而不是让它只是代价。核心思路：**代价必须是"需要决策的"，而不是"无法应对的"。** 一个缺少位移的英雄应该得到某种**主动的、有成本的**应对工具（例如可用于规避关键一击的短时防御窗口、或需要预判的换位手段），而不是被动挨打。
3. **对位预期的可读化**：在选人阶段就让玩家看得见阵容的标签空缺与相性方向（不是告知胜负，而是告知"我们缺什么"）。

| 项目 | 内容 |
|---|---|
| **预期效果** | 对位从"0/1"变成"六四开"；BP 从"锁死"变成"交换"；弱势方的操作空间变成真实可用的 |
| **配套措施** | 需要配套的 UI 教学（把反制关系变成玩家可感知的常规知识），否则反制标签等于不存在 |
| **风险** | ① 标签数量上升会抬高认知负担，必须坚持"每个英雄只拥有少量标签"的纪律；② 反制手段普及会让位移类英雄整体贬值，需要同步调整位移的潜在收益；③ 相性可视化若做得过强，会变成"选人即定胜负"，反而加剧问题一 |

### 方案 C：把"关键状态"做成可读的分级信息，而不是零信息或全信息

**要解决的问题：** 问题四（强度与可见性不匹配）。

**机制怎么改（分层设计，而不是一刀切）：**

| 信息层级 | 呈现方式 | 服务人群 | 设计意图 |
|---|---|---|---|
| 自身状态 | 完整数值/进度 | 所有玩家 | 保证执行层的诚实性 |
| 对手"是否可用" | 模糊状态提示（就绪/冷却中，不显示精确剩余） | 中等及以上玩家 | 把"猜测"变成"有依据的判断" |
| 对手精确冷却剩余 | 不提供（保留为技术资产） | 高端玩家 | 保留"计时"这一技术上限 |
| 关键技能**命中后的**反馈 | 短暂的状态变化反馈 | 所有玩家 | 让"他刚交了技能"成为客观事实而非记忆 |

**关键设计原则：提供的是"事实"，不是"结论"。** 告诉玩家"他刚刚用了那个技能"，而不是"你可以现在上"。前者把判断权留给玩家，后者替玩家做决定。

| 项目 | 内容 |
|---|---|
| **预期效果** | 中等玩家的进场决策从"赌"变成"读"；高端玩家的计时技术仍保留价值（因为提示不提供精确剩余）；对局的可解释性上升，玩家的挫败更容易被归因为"我的判断"，而非"游戏不公" |
| **配套措施** | 视觉语言必须与游戏整体美术风格一致，避免变成"血条旁边一堆仪表"；需要少量但稳定的反馈音效区分就绪/冷却 |
| **风险** | ① 削弱"记 CD"类技术资产，需通过"提示精度"控制（模糊化而非精确化）来平衡；② 界面信息密度上升，可能对小屏设备不友好；③ 需要一段时间的玩家习惯迁移 |

### 附：支撑上面三个方案的一条设计纪律

这三个方案要真正落地，都需要一条流程上的保障，我把它单独写出来，因为它比任何单个机制都更重要：

> **任何一次英雄改动，都必须同时提交两张表：改动前后的"能力标签向量表"与"该英雄的目标定位"。如果改动删除了该英雄的核心标签，就必须同步给出叙事、视觉、教学层面的补偿方案，并把它定义为"重做"而非"削弱"。**

这条纪律解决的是问题三（身份漂移）。它的价值不在于限制改动，而在于**让改动变得可解释**：当玩家能理解"他不是被削了，是被重新定义了"，接受度会完全不同。

## 8. 这套拆解能力如何迁移到雷火的战斗策划工作

我不是为了写这份文档才去建这些框架的。上面每一章，都对应我在别的作品里实际用过的工具。这一章把"拆解能力"直接映射到岗位职责上。

| 本文档的拆解 | 对应的工作场景 | 我在本作品集中的证据 |
|---|---|---|
| **五层时间尺度**（第 1 章） | 新战斗系统的结构定义：立项时先分清"哪一层解决哪个问题"，避免错层开药方 | 作品 ① 《止戈》战斗系统设计白皮书，以帧层为地基向上搭五层结构 |
| **能力标签体系**（第 2 章） | 英雄/职业/武器的能力组合设计，以及克制关系的可解释化 | 作品 ① 的反制矩阵设计；本文第 2 章的标签库可直接作为设计检查表 |
| **三组核心矛盾**（第 3 章） | 设计对抗体验的张力区间：先手/后手、爆发/持续、个体/团队 | 作品 ① 的"杀势系统"即解决优势不可逆问题 |
| **平衡旋钮矩阵**（第 4 章） | 版本迭代的操作手册与风险评估：改什么、改多少、玩家会怎么理解 | 作品 ② 的蒙特卡洛仿真用于验证调整后的目标区间 |
| **两种平衡哲学**（第 5 章） | 平衡策略的选择与沟通口径，避免"只做加法"导致的强度通胀 | 作品 ② 的仿真输出直接对比"削弱"与"加强"两种策略的分布差异 |
| **玩家体验反推设计缺陷**（第 6 章） | 把玩家反馈翻译成可修改的结构问题，而不是直接改数值 | 本文档本身即为一次完整的翻译示范 |
| **可落地改进方案**（第 7 章） | 提出可执行方案并自带风险评估与配套措施——这是面试与实际工作最稀缺的能力 | 本文第 7 章的三个方案均含"预期/风险/配套"三段 |

### 8.1 我认为自己最值得被检验的三项能力

**第一，把体感翻译成变量。** 一个做了 10000 小时的玩家，如果只能说"这个英雄太强了"，那 10000 小时只是消费。我在本文中做的事，是把"太强了"拆成"标签溢出 / 反制成本过高 / 环境耦合"三种可区分的病因，并给出各自的修法。**这个翻译动作，就是战斗策划的日常。**

**第二，先问结构、再问数值。** 绝大多数平衡争议，最终都收敛到"要不要加/减一个数"上，但真正的答案往往在结构层。第 2.4 节的"标签溢出/标签空缺"诊断、第 5.4 节的决策树，都是为了让讨论在动手改数字之前先找对层面。

**第三，默认方案自带风险与配套。** 第 7 章每个方案我都写了"预期效果 / 风险 / 配套措施"。这不是形式，而是我对设计方案的基本要求：**一个只讲好处的方案不是方案，是愿望。** 真正的战斗策划要能回答"改完之后谁会受损、我们准备怎么接住他"。

### 8.2 我知道自己缺什么

写这份文档的过程中，我也清楚自己的短板在哪，一并写在这里，因为我认为这是可以被验证的诚实：

| 我的局限 | 说明 | 我的弥补路径 |
|---|---|---|
| **缺少内部数据** | 我只能看到体感与公开机制，看不到分层胜率、禁用率、对位相性等真实数据 | 用可玩原型 + 蒙特卡洛仿真自建数据闭环（见作品 ① ②） |
| **缺少真实工程约束** | 我不知道一个机制改动的实现成本、性能预算与排期代价 | 已完成的浏览器原型让我的手感设计跑在真实帧率下，初步建立对实现成本的感知 |
| **经验集中在少数品类** | 我的深度主要来自 MOBA 与战术竞技，对动作/ARPG/载具等其他战斗品类的体感积累较薄 | 用同一套分层框架拆解其他品类，检验框架的可迁移性 |

**我认为一个求职者最有说服力的地方，不是宣称自己什么都会，而是能清楚说出"我的框架在哪里成立、在哪里需要被数据修正"。** 这套拆解方法可以立刻上岗使用，它的误差需要用真实数据来收敛——而我很想在有数据的地方继续做下去。

## 附录 B：本文档的事实边界

为了不让这份拆解变成"看起来很懂的断言",我明确标注本文的证据等级：

| 内容 | 证据等级 | 说明 |
|---|---|---|
| 段位体系、分路结构、装备与召唤师技能的存在与作用方向 | **公开可验证** | 游戏内公开信息与对局常识 |
| 硬控/软控/霸体/解控/位移/重伤/真实伤害等机制概念与相互作用方向 | **公开可验证** | 对局中可观察、官方说明可查 |
| 具体英雄的技能功能描述（如"以压制级控制著称""以多段位移著称"） | **公开可验证** | 仅描述功能标签，不评价其强弱 |
| 对位相性、强度曲线、版本改动因果的具体判断 | **个人观察与推断** | 基于 10000+ 小时的对局经验归纳，未使用官方数据验证 |
| 第 7 章三个改进方案的参数（帧数、量级） | **示意/推导** | 仅为说明设计意图，实际值必须在原型中实测标定 |
| 任何具体伤害、冷却、系数数值 | **本文不使用** | 无法证实的数字不进入设计讨论 |

**一条我坚持的原则：能证实的说事实，不能证实的说推导，两者不混着说。** 这是玩家和策划之间最本质的区别——玩家可以说"我感觉"，策划必须能指出"这个感觉对应哪个变量、以及怎么验证它"。

## 结语

这份文档想证明的只有一件事：

> **我不是在描述一款游戏，我是在拆解一个系统。**

一款运营多年的 MOBA 能在这么多版本里持续运转，说明它的对抗结构是经过大量验证的——**它是一份公开的、可以被反复阅读的设计教材**。我用了 10000 小时去玩它，又用了这份文档把那些小时里的直觉，整理成可以被讨论、被修改、被验证的语言。

如果雷火需要的是一个能听懂"玩家在抱怨什么"、并且能把这句话变成"我们下个版本动哪个旋钮"的人，我认为这份拆解就是我的答卷。

*—— 黄渊 · 2027 届 · 华北电力大学*
